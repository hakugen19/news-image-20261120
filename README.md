A program that draws a newspaper front page summing up the world's news of Friday 20 November 2026 — the Shenzhen trilateral summit and its joint peace declaration, the World Court ruling that Myanmar is responsible for genocide against the Rohingya, Cyclone Akvan's landfall in Odisha, a Houthi missile hitting a Riyadh skyscraper, Russian missiles falling in Poland, the AI stock sell-off, and briefs on Iran, Voyager 1 and Haiti — and writes it to /output/entry.png. Pure Python 3 standard library (a tiny built-in bitmap font and shape drawing, PNG encoded with zlib), no network, deterministic: two runs produce identical bytes.

## Run it

```sh
python3 main.py
```
